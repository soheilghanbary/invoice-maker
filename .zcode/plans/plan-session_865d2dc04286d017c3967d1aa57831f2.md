# Invoice Form Redesign + State Cleanup

**Decisions (yours were not returned, so I'm proceeding with the recommended options — flag anything you disagree with):** "Quiet ledger" visual direction · remove the dead PDF-download feature · scope = form page + preview sheet. The staged uncommitted changes (neutral shadcn token refresh, deleted `/api/invoice-pdf`, shadcn bump) are kept as the base to build on.

## Design contract (Phase 1 — "Quiet ledger")

An accountant's precise desk: paper-white surfaces, ink-slate text, one committed accent (keep sky `#0369a1` as brand), ruled ledger lines, tabular Persian numerals, compact professional density. No decoration that doesn't carry information (icon chips go; quiet section titles + hairline rules stay). Light theme only, RTL throughout with logical properties (`ms-/me-/ps-/pe-`).

- **Tokens** (`globals.css`): neutral `--background` (cool off-white), white cards, slate hairline `--border`, sky `--ring`, keep `--primary: #0369a1`. Print block unchanged.
- **Layout**: keep two-column grid (form | sticky summary), tighter 8px rhythm. Mobile: the summary becomes a fixed bottom action bar (total + save + preview icon) instead of stacking after the form.
- **Items**: real column-header row on desktop (نام | شرح | تعداد | قیمت واحد | جمع | حذف) instead of repeated labels; mobile keeps cards.
- **Summary**: ledger rows with dotted leaders, inline discount, VAT toggle row, big total, one primary CTA.
- **Preview sheet**: same language — neutral header, sky kept in the printed table header; print mechanics untouched.

## Phase 2 — State refactor & cleanup

1. **FormProvider**: wrap sections in RHF `FormProvider`; sections switch to `useFormContext()`. Deletes all `control`/`register` prop drilling.
2. **Delete the zustand store** (`invoice-form-store.tsx` removed; only the root ever read it). Root holds plain `useState`: `loading`, `loadFailed`, `loadError` (page-level) split from `actionError` (save/stamp, shown as an alert near the summary — today one `saveError` mixes all concerns). `timeZone` stays effect-set to avoid hydration drift. Remove the now-unused `zustand` dep.
3. **Validation without new deps**: RHF built-in rules (`mode: "onBlur"` + submit) mirroring what `saveInvoice` enforces — required `number`/`date`/`buyer.name`, item quantity/price required + `min 0` with `setValueAs`. Inline error text via the `Field` component (`aria-invalid`, `formState.errors`); RHF focuses the first invalid field on submit. Storage-layer validation stays as the last line of defense.
4. **Single source of truth for totals/tax**: `invoice-storage.ts` imports `calculateTotals` + exported `TAX_RATE` from `model.ts`; delete its duplicate `calculateTotal` and the no-op `stampPreview` spread line.
5. **Shared formatters**: `invoices-list.tsx` local `formatMoney`/`formatDate` replaced with `model.ts` exports.
6. **`normalizeInvoiceValues()` helper** in `model.ts` — one place that merges a stored payload over defaults (items array included — today a legacy record without `items` loads as `undefined`), clamps discount/quantities. Used by the edit-load effect.
7. **Invoice number**: `generateInvoiceNumber()` in `model.ts` (Persian year derived via `fa-IR-u-nu-latn`, not hardcoded `۱۴۰۵`); default `number: ""` filled by the existing one-shot effect (localStorage counter mechanism unchanged — noted as future work to move it to the DB).
8. **Navigation**: `router.push("/invoices")` instead of `window.location.assign`.
9. **Remove the PDF feature end-to-end**: `downloadPdf` fn, `downloadingPdf` state, button (done in Phase 1), `playwright` dep + `playwright:install` script via `bun remove playwright`.
10. **Remove the items-section mounted-gate double component** (single component with `useFieldArray`; verified against hydration in dev).
11. `seller-profile-persistence.tsx`: switches to FormProvider; behavior preserved (write debounce added).
12. Hide the summary aside when the invoice failed to load (today it renders zeros next to the error card).
